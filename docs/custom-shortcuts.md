# Custom keyboard shortcuts

The operating system's alternate Cut gesture (Shift+Delete on Windows) continues to work
independently of the X shortcut. In vector edit mode it removes selected points and heals the
path; outside edit mode it cuts the selected layers.

Help → Keyboard shortcuts lists the default shortcuts and commands available without extra
parameters that have no default key.
Search by command name or id, click its row, then press the new chord. Escape cancels recording.
The press, text/clipboard events generated by it, held repeats and its release belong to recording;
they do not run a command or type into the canvas or the search field.

If a chord already belongs to a command in an overlapping context, the panel names its owner.
Cancel keeps both commands unchanged. Replace shortcut removes that chord from its old owner,
preserves the owner's other alternatives, and assigns it to the selected command.

Right-click a command to reset its default or remove its shortcuts. A row reset also asks before
displacing another owner. Reset all shortcuts restores the defaults for this platform. macOS and
Windows/Linux overrides are saved separately in preferences; old preferences load the defaults.
Menus, Actions, toolbar/property tooltips, control `engine.commands`/`ui.key`, and headless MCP
resolve the same overrides. A command without a key displays Unbound.

Escape remains the interaction-cancel key. Held canvas gestures (Space, Z and arrows), contextual
plain Enter/Delete/Tab keys, and native clipboard chords cannot be assigned to another command.
Text fields retain their operating system editing keys, and commands live in their original
canvas/text contexts. A shortcut that also runs while editing text requires Cmd/Ctrl or Alt so
ordinary typing stays typing (the region-navigation keys keep their navigation behavior).
Shortcuts that save a file still commit an active panel field before saving.

Automation uses these undo-free preference commands:

```json
{"command":"pref.shortcut","params":{"id":"file.versionHistory","keys":["Alt+F8"],"platform":"mac"}}
{"command":"pref.shortcut","params":{"id":"file.versionHistory","keys":[],"platform":"mac"}}
{"command":"pref.resetShortcut","params":{"id":"file.versionHistory","platform":"mac"}}
{"command":"pref.resetShortcut","params":{"platform":"mac"}}
```

`platform` is `mac` or `other`, defaulting to the host platform. Set/reset returns
`{"changed":false,"conflicts":["command.id"]}` without modifying preferences when an owner
would be displaced. Repeat with `replace:true` after an explicit user choice. Canonical defaults
remain in `engine::keymap::KEYS`; replacements never mutate that table.
