# Starter icons

Open **Icon set starter** from Home → Templates or File → New from template. The template
contains 64 editable components, named `Icon/<name>`, on a 24 px grid with a shared `Icon/Stroke`
colour style and 2 px round strokes. Drag them from Assets or copy a component into your design.
The anatomy board explains the grid and keylines; four instances demonstrate 16, 24, 32 and
48 px sizes.

The original 24 icons retain their names, outlines and order. Forty more cover files and editing,
navigation, media, devices, communication, security and shopping. The last icon is **Credit card**.
All outlines are original code drawn for FigCraft. No third-party artwork, icon font or external
asset library is required.

Native `.figcraft` saves keep the components and shared style. SVG exports keep vector geometry;
SVG import treats an exported component as editable shapes. Experimental `.fig` exports are
checked through FigCraft's own importer; this does not establish compatibility with every
external editor.

Through the command interface, use `file.newFromTemplate` with `{"template":"icon-set"}`.
