# Automatic Board elbow obstacle routing

Native Board elbow connectors without a manually reshaped path can route around unrelated visible Board shapes and sticky notes on the same page. The router uses conservative page-space bounding boxes, intersected with ancestor clip bounds. Endpoint owners and their ancestry are excluded. Automatic Box attachments keep the existing four-page-unit gap and side-normal departure; explicit On and free Point coordinates stay exact.

Shape creation, deletion, movement, resizing, reparenting, visibility and ancestor transform/clip changes refresh the derived route and label inside the existing command transaction. One Undo restores the obstacle and route together. Manual Runs/Bow paths, Straight and Curved styles, and imported vector-only paths keep their existing behavior. Older native automatic routes refresh into the clean loaded baseline; supplied model, live-welcome, version and branch authority is unchanged.

The obstacle snapshot belongs to a single current-document query or settlement, with no cross-frame cached detour. New avoidance work is bounded: 16,384 node inspections plus one overflow sentinel; 64 parent links per chain; 16 page contexts; 256 obstacles per page and 1,024 total; 262,144 counted traversal/collision/search work units shared by the settlement; at most64 searches. A search has at most32 active obstacle rectangles plus endpoint boxes, 4,096 grid intersections, 8,192 directional states/queued entries, four validated replans and64 final points. Each accepted route is checked against the complete collected obstacle set.

An incomplete, malformed, overflowing, blocked-stub or exhausted search returns the freshly computed legacy endpoint-only route. Later connectors also receive fresh fallback geometry rather than keeping a detour validated against an earlier obstacle position. Dense/overlapping scenes or documents beyond those budgets can still cross shapes. These limits cover the added avoidance work, not all existing document normalization, text measurement, legacy geometry, stack/RSS or rendering work.

This is a bounded partial fix for #1707. Parallel-connector lane distribution remains unresolved. Arbitrary layer silhouettes, exact masks/rotated outlines, paint occlusion, effects and stroke expansion are outside this conservative Board-owner scope. No asset or dependency is added.
