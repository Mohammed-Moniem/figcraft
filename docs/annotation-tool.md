# Annotation tool

Shift+T chooses Annotation in Design or Inspect. Choose a layer on the canvas, write a note, optionally pin existing inspected properties and choose an existing category, then press Enter or Add annotation. Shift+Enter inserts a newline. The note field or submit button must own Enter; property/category pickers and IME confirmation keep their keys. The tool also appears in the Text flyout, Tools menu/Actions, and the layer context menu's Add annotation action. Customized shortcuts use the existing resolved keymap.

The composer is transient. Escape cancels its draft; another Escape follows normal tool behavior. No document edit or Undo step exists until the existing annotation.add command succeeds. A draft belongs to one window/viewport, document presentation, page, tool and captured layer object. Switching any owner, entering presentation or a read-only state, deleting/editing the target, or losing window focus retires it and its editor/pickers. An uncommitted IME composition also cannot transfer to another widget; disabling IME while the note owns it cancels only its candidate text. Reopening starts empty. A successful submit is one existing annotation edit, saved on the layer and undone in one step.

Callouts show in Inspect and while Annotation is selected in Design. Pinned properties keep their existing live inspection values; categories and saved annotation data use the existing model. Version previews, view-only live documents and library copies cannot author annotations. Existing plain T, canvas text editing and Comment retain their owners.

This implements the missing #1840 activation/authoring path for layer-attached annotations. It does not add free annotation anchors, repositioning, category redesign, measurement Shift+M or broader parity. Source: [Accessibility at Figma](https://help.figma.com/hc/en-us/articles/35063862380311-Accessibility-at-Figma), [Add measurements and annotate designs](https://help.figma.com/hc/en-us/articles/20774752502935-Add-measurements-and-annotate-designs).
